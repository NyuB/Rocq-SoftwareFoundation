# Logical Foundations exercises

This is my fork of [Logical Foundations](https://softwarefoundations.cis.upenn.edu/) exercises, (see the original [README](README))

## Correct an exercise

Assuming `<Exercise>` is the prefix of an `<Exercise>.v` file:

- Linux: `./correct.sh <Exercise>`
- Windows: `./correct.bat <Exercise>`
